# Try a Threads draft before connecting / 先試 Threads 草稿，再連帳戶

**English.** The README opens with a real release note, an example Threads draft and a prompt to use with your own notes. A downloadable browser demo works offline without a SosoAPI account. It formats custom notes locally; an AI rewrite happens only when you take the prompt to your own agent. The publishing guide distinguishes drafting, connecting and requesting a post.

**Verified.** Opened the exact single-file demo from disk in Chromium, offline. Checked both samples, custom and empty input, the 500-character limit and a 320 px layout; no external requests. Validated local Markdown links and ran the six existing account-selection tests. No sign-in or publishing was needed or exercised.

**廣東話。** README 第一屏由真實 release note 開始，先睇一條 Threads 草稿，再用自己嘅資料試。瀏覽器 demo 下載後可以離線用，唔使 SosoAPI 帳戶；自訂筆記由本機整理，想用 AI 改寫先將 prompt 貼去自己嘅 agent。指引分清寫草稿、連帳戶同確認發帖。

**實測。** Chromium 離線直接打開該 HTML，試過兩個範例、自訂同空白輸入、500 字元限制同 320 px 闊度，冇對外網絡請求。本機 Markdown 連結同現有六項帳戶選擇測試都通過；冇登入或實際發帖。
